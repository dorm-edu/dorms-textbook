# 2단계: 펼침 설계

한 펼침 = 한 생각. 펼침마다 아래 틀을 기본으로 한다(필요 없는 칸은 뺀다).

| 칸 | 자리 | 하는 일 |
|---|---|---|
| title | 왼쪽 쪽 맨 위 | 이 펼침의 질문이나 생각을 짧게(40자 이내) |
| body | 왼쪽 쪽 | 1~3문단, 학생 말투로 짧게 |
| equation | 왼쪽 쪽 상자 | 핵심 식 하나와 말로 풀어 쓴 설명 |
| keywords | 왼쪽 쪽 | 핵심 낱말 2~4개와 뜻 |
| predict | 왼쪽 쪽 | 그림을 만지기 **전에** 예측(보기 2~5개) |
| scene + task | 오른쪽 쪽 | 3D 그림. 학생이 누르거나 끌어서 예측을 확인 |
| shots | 아래 막대 재생 | 카메라 연출 + 자막으로 시연(3~6컷) |
| flap | 왼쪽 쪽 날개 | 예측 뒤에 들춰 보는 이유 |
| margin | 왼쪽 여백 | 그림을 움직일 때 바뀌는 손글씨 계산 |
| challenge + complete | 여백, 도장 | 해 볼 도전. 달성하면 `S.complete()` 로 도장 |
| check | 왼쪽 쪽 | 마지막 펼침에서 확인 문항(정답 번호 지정) |

## 좋은 그림 쪽의 기준
- 그림이 **움직여야 이해되는 것**을 보여 준다. 글로 충분한 것은 그림으로 만들지 않는다.
- 학생 손이 닿는 곳이 분명해야 한다: 누르는 물체는 `S.tappable`, 끄는 점은 `draggable`, 값은 `S.slider`.
- 값이 바뀌면 그림·여백 계산·읽기 숫자가 **같이** 바뀐다.
- 물체는 쪽 안(x -10~10, z -13~13)에 놓고, 그림 설명 글(쪽 아래 z 8 이후)을 가리지 않는다.

설계를 표로 선생님에게 보여 주고 확인받은 뒤 3단계로 간다.
