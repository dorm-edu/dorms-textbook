# 4단계: 직접 보고 확인하기

**눈으로 보지 않은 화면은 확인한 것이 아니다.** 아래 순서를 따른다.

## 화면 도구 찾기
1. 지금 쓸 수 있는 브라우저 조작 도구가 있는지 먼저 확인한다(예: Playwright MCP, Chrome DevTools MCP, 내장 브라우저, Claude in Chrome).
2. 없으면 선생님에게 한 줄로 알리고 설치한다. 가장 쉬운 길: `npx -y playwright install chromium` 뒤 짧은 Node 스크립트로 열어 화면을 찍는다.
3. 설치가 막히면 선생님에게 브라우저로 미리보기를 열어 달라고 하고, 화면 캡처를 받아 본다.

## 웹 대화창이라 화면 도구가 없을 때
`preview_lesson({ source })`(고칠 때는 `{ lesson_id, edits }`)을 부른다. 서버 브라우저가 펼침마다 넓은 화면·휴대폰 캡처와 문제 목록을 돌려준다. 캡처를 아래 목록대로 하나씩 직접 보고, 누르기·끌기처럼 캡처로 알 수 없는 것은 선생님에게 미리보기 주소에서 눌러 봐 달라고 부탁한다.

## 확인할 것 (펼침마다, 넓은 화면 1440×900 과 휴대폰 390×844 둘 다)
- 콘솔 오류 0개, `window.__dt.errors` 비어 있음, `window.__dt.invalid` 없음.
- 오른쪽 쪽 3D 그림이 쪽 안에 있고 그림 설명 글을 가리지 않는다.
- 왼쪽 쪽 글이 넘치거나 잘리지 않는다(날개가 글을 덮지 않는다).
- 누를 것·끌 것이 실제로 동작한다: 예측 고르기, 날개 들추기, tappable 누르기, 점 끌기, 슬라이더.
- 시연(재생 단추)이 끝까지 돌고 자막이 맞다.
- 수학·과학 값이 맞다: 화면에 보이는 숫자를 직접 계산해 대조한다.
- 쪽 넘김(다음·이전)이 깨지지 않는다.

찾은 문제는 모두 고친 뒤 다시 확인한다. 깨끗해지면 5단계로 간다.
