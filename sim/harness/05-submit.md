# 5단계: 제출

`submit_lesson({ source, title, unit_code, standards, note })` 로 lesson.js 내용을 그대로 올린다. 이미 있는 차시를 고친 판이면 `lesson_id` 를 함께 주고, 웹 대화창에서는 `source` 대신 `edits`(바꿀 부분만)를 줘도 된다.

## 제출 횟수를 아낀다 (안전장치)
- 선생님 한 분당 **하루 30번**까지 제출할 수 있다. 결과에 남은 횟수가 함께 온다. 매번 확인한다.
- 제출은 **4단계를 다 통과한 뒤 한 번**에 한다. 작은 수정마다 제출하지 않는다.
- 서버 검사에서 떨어지면 결과의 이유를 **전부** 고친 뒤 다시 제출한다.
- **같은 이유로 세 번 넘게 떨어지면 멈추고** 선생님에게 상황을 설명한다. 자동으로 계속 다시 내지 않는다.

## 통과하면
- 결과의 **수업 링크**를 선생님에게 그대로 알려 준다. 선생님 수업에서는 바로 쓸 수 있다.
- 교과서 공개 목록에는 운영자 확인 뒤 실린다고 알려 준다.
- 그다음 6단계로 간다.
