# 단원-성취기준 매핑 작업 지침 (모든 그룹 공통)

입력: pending/gN.json — 배열. 각 원소 = 한 교과(학교급·학년군·과목).
- `units`: 아직 매핑되지 않은 도름스 단원 목록 (unitCode, unit). 단원명은 교사들이 이미 정한 것으로 절대 바꾸지 않는다.
- `otherUnitsAutoMapped`: 같은 교과에서 영역명이 고시 영역과 똑같아 이미 자동 매핑된 단원 (참고용, 다시 매핑하지 않음).
- `standards`: 그 교과에 해당하는 2022 개정 교육과정 고시 성취기준 전체 (code, officialSubject, area=고시 영역, subarea, text). 원문 그대로이며 이것만 사용한다.

할 일: `units`의 모든 단원 각각에 대해, 그 단원에서 다루는(가르칠) 내용에 해당하는 성취기준 code를 `standards`에서 골라라.
판단 원칙:
1. 단원명이 고시 영역명과 표기만 다르면(띄어쓰기·가운뎃점·괄호 등, 예: "이해(듣기)"→영역 "이해" 중 듣기 관련) 의미로 맞춘다. 영역 일부만 해당하면 그 부분만(예: 듣기 관련 성취기준만).
2. 교과서식 단원명(예: "9까지의 수", "소인수분해", "기행문을 써요")은 내용상 그 단원에서 직접 다루는 성취기준만 고른다. 너무 넓게 잡지 말고, 하나도 없으면 빈 배열.
3. 2015 개정식 옛 영역명(예: 사회 "지리 인식", "정치", "역사 일반")이나 2022 고시에 없는 영역·주제(예: 통합교과 "봄", "학교")는 의미상 대응되는 성취기준을 고르고, 반드시 mismatch에 그 사정을 적는다.
4. 학년군 성취기준(예: 중학교 1~3학년)이라 학년 구분이 고시에 없으면, 단원 내용 기준으로만 고른다.
5. code는 반드시 입력 standards에 있는 것만. 지어내지 말 것. 같은 code를 여러 단원에 줘도 된다.
6. reason은 짧은 한국어 한 줄(왜 이 성취기준들인지). mismatch는 단원명과 고시 영역/구조가 다르거나 판단이 애매하면 한 줄로(없으면 빈 문자열). confidence는 high/medium/low.

출력: mapped/gN.json 에 Write 도구로 저장 (반드시 파일로 저장할 것 — 최종 응답이 유실될 수 있음).
형식: { "<unitCode>": {"unit": "<단원명>", "subject": "<입력 key>", "codes": ["..."], "reason": "...", "mismatch": "...", "confidence": "high|medium|low"}, ... }
입력 units의 모든 unitCode가 빠짐없이 들어 있어야 한다. 저장 후 python3 -I 로 JSON 파싱과 개수(입력 units 수와 같은지), 모든 code가 입력 standards에 있는지 스스로 검사하고, 최종 응답은 "gN 완료: 단원 X개, 빈 매핑 Y개" 한 줄만.
파일은 pending/·mapped/ 밖에 쓰지 말 것. 다른 파일·저장소는 건드리지 말 것.
